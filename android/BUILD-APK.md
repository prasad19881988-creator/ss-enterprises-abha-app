Open this `android` folder in Android Studio.
Select Build > Generate App Bundles or APKs > Generate APK(s).
For a release build, use Build > Generate Signed Bundle / APK and create/use your signing key.


### Important
Android app opens the existing live ABHA portal; it does not create a new Render service. Keep the current GitHub/Render service and update its `master` branch only after testing.
